# Employee Management System:
A college project that helps an organization manage its employees in one place. It handles employee records, attendance, leave requests and payroll, with separate access for Admin, HR Manager and Employee.
About the Project:
Managing employee data on paper or in scattered spreadsheets is slow and error-prone. This system stores all employee information in a database and automates routine tasks like marking attendance, approving leave and calculating salary, so the organization saves time and avoids mistakes.

# User Roles
Admin: manages users, departments and overall system settings, and views reports.

HR Manager: manages employee records, approves leave, handles payroll and generates reports.

Employee: logs in, views and updates own profile, marks attendance, applies for leave and views payslips.

# Technologies Used

 

Programming language: Python / Java / PHP

Database: MySQL

Front end: HTML, CSS, JavaScript

Tools: Git, GitHub, VS Code
